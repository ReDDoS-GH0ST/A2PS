📌 A2PS (Advanced Powerful Pentest Suite) - это мощный фреймворк для полного тестирования на проникновение: разведки, анализа и даже атаки! Фреймворк полностью написан на Python, но в дальнейших версиях будут подключаться и другие языки программирования. Его философия - "Nmap scanner, MSF spirit". Проект постоянно развивается и расширяет свои возможности!

<p>📦 Требования:</p><ul>
  <li>Права администратора/root-пользователя перед запуском (необязательно, но желательно для использования всех скриптов)</li>

<p>⚙️ Установка:</p>
<p>Для использования всех возможностей A2PS - запускайте от имени администратора или root-пользвателя</p>
<p>Для Windows:</p><ol>
  <li>Скачайте репозиторий</li>
  <li>Установите библиотеки, введя следующую команду в терминале или в командной строке: <code>pip install -r "Путь/к/файлу/requirements.txt"</code></li>
  <li>Запустите командную строку или терминал от имени администратора и запустите программу, введя команду: <code>python "Путь/к/файлу/A2PS.py"</code></li>
  <li>Готово!</li>
</ol>
<p>Для Linux:</p><ol>
  <li>Откройте терминал</li>
  <li>Введите команды:</li>
     <code>git clone https://github.com/ReDDoS-GH0ST/A2PS.git</code><br>
     <code>cd A2PS</code></li>
  <li>Установите библиотеки, введя следующую команду в терминале: <code>pip install -r "Путь/к/файлу/requirements.txt"</code></li>
  <li>Запустите терминал и запустите программу, введя команду: <code>sudo python "Путь/к/файлу/A2PS.py"</code></li>
  <li>Введите пароль от root-пользователя и нажмите Enter</li>
  <li>Готово!</li>
</ol>
<hr>
<p>🛠 Использование:</p>
  <p>Используйте допустимые команды:</p>
  <ol>
    <li><code>scanp</code> - для сканирования открытых портов</li>
    <li><code>showtar</code> - для сканирования доступных устройств в текущей сети</li>
    <li><code>showscr</code> - для просмотра доступных скриптов</li>
    <li><code>help</code> или <code>doc</code> - для вывода документации по использованию A2PS</li>
    <li><code>restart</code> - для перезапуска A2PS</li>
    <li><code>clear</code> - для очищения терминала</li>
    <li><code>banner</code> - для вывода баннера</li>
    <li><code>--version</code> - для просмотра текущей версии A2PS</li>
    <li><code>quit</code>, <code>exit</code> или <code>Ctrl+C</code> - Для выхода из программы</li>
  </ol>

<p>Для первых двух команд доступны аргументы, позволяющие:</p>
    <ul>
        <li>Видеть подробный процесс</li>
        <li>Подключать скрипты и плагины</li>
        <li>Выводить документацию по использованию этих команд</li>
        <li>Делать расширенный поиск и анализ</li>
    </ul>
<p>Во второй версии будут добавлены движки, новые скрипты и многое другое</p>
